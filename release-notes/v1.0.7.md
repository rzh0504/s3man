## What's Changed

- Added an upload option to convert supported images to WebP while keeping compression quality controls linked to the existing presets.
- Kept original-format image compression behavior unchanged when WebP conversion is disabled.
- Fixed converted uploads so file names, MIME types, transfer records, and S3 object keys consistently use the final `.webp` name.
- Updated the upload settings UI with an RNR-style WebP switch and clearer filename validation.
- Removed upload configuration tooltips that were no longer needed.
- Added an About row in Settings that displays the current app version.
- Updated Expo SDK 55 dependencies and aligned React Navigation packages to avoid duplicate navigation contexts.
