## 更新内容

- 升级到 Expo SDK 56，更新 React Native、Expo Router、Reanimated、TypeScript 等 SDK 对齐依赖。
- 适配 Expo Router SDK 56 的导航入口变化，移除对 `@react-navigation/*` 的直接依赖。
- 调整启动屏配置到 `expo-splash-screen` 插件，兼容 SDK 56 配置校验。
- 修复暗色模式主题不会持久化的问题，重启应用后会恢复上次选择的亮色或暗色主题。
- 修复暗色模式下状态栏样式不同步的问题，Android 状态栏背景和图标颜色会随主题切换。
- 修复 TypeScript 6 下的类型问题，并补齐 `Buffer` 相关运行时导入。
- 修复 GitHub Actions 发布构建中 pnpm 11 拦截 `msgpackr-extract` build script 导致安装失败的问题。

## 升级说明

- 开发环境要求提升到 Node.js >= 20.19.4。
- SDK 56 版本已通过 Expo Doctor、类型检查和现有测试校验。
